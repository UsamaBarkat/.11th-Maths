Exercise 1.1 — Complex Number Operations

Unit 1 · Lesson 2 of 3 🔢 Mathematics ⏱ 20–25 min

🎯 What This Exercise Covers

Exercise 1.1 tests everything from Lesson 1: powers of i, all 4 operations (addition, subtraction, multiplication, division), conjugates, absolute values (modulus), solving complex equations, and the Argand plane.

Try each question on paper first — then reveal the solution to check your work. The goal is to catch your own mistakes, not just read the answers.

📖 Quick Formula Reference

Powers of i

i¹ = i  |  i² = −1  |  i³ = −i  |  i⁴ = 1 (then repeats)

For iⁿ: divide n by 4 → remainder 0→1, 1→i, 2→−1, 3→−i

Conjugate and Modulus

Conjugate of (a + bi) = (a − bi)  → flip the sign of b only

Modulus |z| = |a + bi| = \(\sqrt{a^2 + b^2}\) (distance from origin)

Ordered Pair Notation

(a, b) means a + bi  → first number is real part, second is imaginary part

Multiplicative Inverse

\(z^{-1} = \dfrac{\bar{z}}{|z|^2} = \dfrac{a - bi}{a^2 + b^2}\)

✏️ All Questions — Try First, Then Reveal

Question 1: Evaluate the following

(i)   i¹⁰ · (−i¹²)

i¹⁰:  10 ÷ 4 = remainder 2  →  i¹⁰ = −1

−i¹²:  12 ÷ 4 = remainder 0  →  i¹² = 1  →  −i¹² = −1

Therefore: i¹⁰ · (−i¹²) = (−1)(−1) = 1

(ii)   (−i)¹⁶ · (−i)⁶

(−i)¹⁶ = (−1)¹⁶ · i¹⁶ = 1 · (i⁴)⁴ = 1 · 1 = 1

(−i)⁶ = (−1)⁶ · i⁶ = 1 · i⁴ · i² = 1 · 1 · (−1) = −1

Therefore: 1 · (−1) = −1

(iii)   (i)¹¹ · (−i)¹⁴

i¹¹: 11 ÷ 4 = remainder 3 → i¹¹ = −i

(−i)¹⁴ = (−1)¹⁴ · i¹⁴ = 1 · i¹² · i² = 1 · 1 · (−1) = −1

Therefore: (−i)(−1) = i

Question 2

(i)   For what value of n is iⁿ equal to 1, i, −1, or −i (where 1 ≤ n ≤ 4)?

n = 1: i¹ = i

n = 2: i² = −1

n = 3: i³ = −i

n = 4: i⁴ = 1

Answer: iⁿ = 1 when n = 4 · iⁿ = i when n = 1 · iⁿ = −1 when n = 2 · iⁿ = −i when n = 3

(ii)   Show that iⁿ + i^(n+1) + i^(n+2) + i^(n+3) = 0 for all n ∈ Z

iⁿ + i^(n+1) + i^(n+2) + i^(n+3)

= iⁿ(1 + i + i² + i³)

= iⁿ(1 + i + (−1) + (−i))

= iⁿ(0) = 0   ✓   Hence proved.

Question 3: Simplify the following

(i)   (−6, 3) · (4, −2)

(−6 + 3i)(4 − 2i) = −24 + 12i + 12i − 6i² = −24 + 24i + 6 = −18 + 24i

(ii)   (8, −4) ÷ (−2, 2)

\(\dfrac{8 - 4i}{-2 + 2i}\) × \(\dfrac{-2 - 2i}{-2 - 2i}\)

Numerator: (8 − 4i)(−2 − 2i) = −16 − 16i + 8i + 8i² = −16 − 8i − 8 = −24 − 8i

Denominator: (−2)² + 2² = 4 + 4 = 8

Answer: \(\dfrac{-24 - 8i}{8}\) = −3 − i

(iii)   (2, 3) + (4, 5)  |  (iv) (6 + 5i) − (4 + 3i)  |  (v) (5 − 6i) + (3 + 4i) − (5i − 7)

(iii): (2+4, 3+5) = (6, 8) = 6 + 8i

(iv): (6−4) + (5−3)i = 2 + 2i

(v): 5 − 6i + 3 + 4i − 5i + 7 = (5+3+7) + (−6+4−5)i = 15 − 7i

(vi)   (4 + 5i)(6 + 7i)  |  (vii) (7 + 4i) + (8 + 5i)  |  (viii) (5,−6) + (4,8) − (3,−2)

(vi): 24 + 28i + 30i + 35i² = 24 + 58i − 35 = −11 + 58i

(vii): (7+8) + (4+5)i = 15 + 9i

(viii): (5+4−3, −6+8+2) = (6, 4) = 6 + 4i

Question 4: Simplify

(i)   (2 − i)⁴

(2 − i)² = 4 − 4i + i² = 4 − 4i − 1 = 3 − 4i

[(2 − i)²]² = (3 − 4i)² = 9 − 24i + 16i² = 9 − 24i − 16 = −7 − 24i

(ii) (−1 − i√3)²  |  (iii) (−1 + i√3)²

(ii): 1 + 2i√3 + i²(3) = 1 + 2i√3 − 3 = −2 + 2i√3

(iii): 1 − 2i√3 + i²(3) = 1 − 2i√3 − 3 = −2 − 2i√3

(iv) (1 + i)³  |  (v) (√2 + i)/(√2 − i)  |  (vi) (1+i)/(1−i) · (2−i)/(2−i)

(iv): (1+i)² = 2i → 2i(1+i) = 2i + 2i² = −2 + 2i = −2 + 2i

(v): \(\dfrac{(√2+i)^2}{2+1} = \dfrac{2 + 2i√2 − 1}{3} = \dfrac{1 + 2i√2}{3}\) = 1/3 + (2√2/3)i

(vi): (1+i)/(1−i) = (1+i)²/2 = 2i/2 = i → i · 1 = i

(vii) (2 + i)²/(3 − 4i)  |  (viii) 1/(2 − i)²

(vii): (2+i)² = 3 + 4i → (3+4i)/(3−4i) = (3+4i)²/25 = (9+24i−16)/25 = −7/25 + 24i/25

(viii): (2−i)² = 3 − 4i → 1/(3−4i) = (3+4i)/25 = 3/25 + 4i/25

Question 5: Show z = 1 ± i satisfies z² − 2z + 2 = 0

Show that both z = 1 + i and z = 1 − i are solutions.

For z = 1 + i:

z² = (1+i)² = 1 + 2i + i² = 1 + 2i − 1 = 2i

z² − 2z + 2 = 2i − 2(1+i) + 2 = 2i − 2 − 2i + 2 = 0 ✓

For z = 1 − i:

z² = (1−i)² = 1 − 2i + i² = −2i

z² − 2z + 2 = −2i − 2(1−i) + 2 = −2i − 2 + 2i + 2 = 0 ✓

Question 6: Find conjugate and absolute value of each

(i) 4 + 5i  |  (ii) −1 + 7i  |  (iii) √3 i  |  (iv) √7 − 3i  |  (v) −3 − 4i

(i) Conj: 4 − 5i  |  |z| = √(16+25) = √41

(ii) Conj: −1 − 7i  |  |z| = √(1+49) = √50 = 5√2

(iii) z = 0 + √3i  → Conj: −√3i  |  |z| = √3

(iv) Conj: √7 + 3i  |  |z| = √(7+9) = √16 = 4

(v) Conj: −3 + 4i  |  |z| = √(9+16) = √25 = 5

(vi) (5 − 4i)²  |  (vii) 2/3 − √(−9/16)  |  (viii) (1+i)(1+2i)/(3+i)

(vi) (5−4i)² = 25 − 40i − 16 = 9 − 40i  → Conj: 9+40i  |  |z| = √(81+1600) = 41

(vii) √(−9/16) = (3/4)i → z = 2/3 − (3/4)i  → Conj: 2/3 + (3/4)i  |  |z| = √(4/9 + 9/16) = √145/12

(viii) Numerator: (1+i)(1+2i) = 1+2i+i+2i² = −1+3i  → (−1+3i)/(3+i) = (−1+3i)(3−i)/10 = (−3+i+9i−3i²)/10 = 10i/10 = i  → Conj: −i  |  |z| = 1

Question 7: Find real and imaginary parts

(i) 2i(3 − 5i)  |  (ii) (√5 + i)/(√5 − i)

(i): 6i − 10i² = 10 + 6i  → Re = 10, Im = 6

(ii): Multiply by conjugate → (√5+i)²/6 = (5+2i√5−1)/6 = (4+2i√5)/6  → Re = 2/3, Im = √5/3

Question 8: If z = x + iy, Re(z) = 0 and |z| = 2, find z

Find all values of z.

Re(z) = 0 → x = 0, so z = iy

|z| = |y| = 2 → y = ±2

Answer: z = 2i or z = −2i

Question 9: Solve the complex equations

(i)   (x, y)(2, 3) = (−4, 7)

(x + yi)(2 + 3i) = −4 + 7i

Expand: (2x − 3y) + (3x + 2y)i = −4 + 7i

Equations: 2x − 3y = −4  ...(1)  |  3x + 2y = 7  ...(2)

Solve: From (1): x = (−4+3y)/2. Substitute in (2): 13y = 26 → y = 2, x = 1

Answer: x = 1, y = 2

(ii) (x + 3i)² = 2yi  |  (iii) (x + 2yi)² = xi

(ii): x² + 6xi − 9 = 2yi → Real: x²−9=0 → x=±3  |  Imag: 6x=2y

If x=3: y=9  |  If x=−3: y=−9 → (3,9) or (−3,−9)

(iii): (x²−4y²) + 4xyi = 0 + xi → Real: x²=4y²  |  Imag: 4xy=x → x=0 or y=1/4

If x=0: y=0  |  If y=1/4: x=±1/2 → (0,0), (1/2, 1/4), (−1/2, 1/4)

Question 10: Plot on Argand plane (describe positions)

(i) (2,−3)  (ii) (3,4)  (iii) (−5,7)  (iv) (−6,−2)  (v) (0,6)  (vi) (−5,0)

(i) 2−3i → right 2, down 3

(ii) 3+4i → right 3, up 4

(iii) −5+7i → left 5, up 7

(iv) −6−2i → left 6, down 2

(v) 6i → on imaginary axis, up 6 (purely imaginary)

(vi) −5 → on real axis, left 5 (purely real)

Question 11: Find the modulus (length of vector)

(i) −5 + 2i  |  (ii) 7/3 + 8i/3  |  (iii) (1+i)/√2  |  (iv) (1 + √3 i)/2

(i): √(25 + 4) = √29

(ii): √(49/9 + 64/9) = √(113/9) = √113/3

(iii): |1+i|/√2 = √2/√2 = 1

(iv): √(1/4 + 3/4) = √1 = 1

⚠️ Mistakes to Avoid in This Exercise

⚠️ Forgetting that i² = −1 (not +1)

In almost every multiplication question, you will get an i² term. Always replace it with −1, never skip this step.

⚠️ Sign errors in conjugate division

When multiplying by conjugate (a − bi), be careful: the denominator becomes a² + b² (always positive). Don't write a² − b².

⚠️ Imaginary part = coefficient of i, not "the i part"

Im(3 − 4i) = −4 (a real number). Not "−4i". This matters in Q7 and similar questions.

📝 Summary

What You Practised in Exercise 1.1

  1. Powers of i follow a cycle of 4 (i, −1, −i, 1). Divide exponent by 4, use the remainder.
  2. For conjugate: flip sign of imaginary part. For modulus: |a+bi| = √(a²+b²).
  3. Solving complex equations: expand, separate real and imaginary parts, solve the system of equations.
