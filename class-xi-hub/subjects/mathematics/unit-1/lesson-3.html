Exercise 1.2

Properties of Complex Numbers — Solutions

🎯 What This Exercise Is About

Just like real numbers follow rules (like 2+3 = 3+2 or 2×3 = 3×2), complex numbers follow the same familiar rules — plus extra rules involving conjugates and modulus. This exercise proves and verifies all of them with real numbers.

📖 Key Properties to Know

Property Formula
Commutative (Addition) \(z_1 + z_2 = z_2 + z_1\)
Commutative (Multiplication) \(z_1 \cdot z_2 = z_2 \cdot z_1\)
Associative (Addition) \((z_1 + z_2) + z_3 = z_1 + (z_2 + z_3)\)
Associative (Multiplication) \((z_1 \cdot z_2) \cdot z_3 = z_1 \cdot (z_2 \cdot z_3)\)
Distributive \(z_1(z_2 + z_3) = z_1 z_2 + z_1 z_3\)
Conjugate Properties — if \(z = a + bi\), then \(\bar{z} = a - bi\)

\(z + \bar{z} = 2a\)  (always real)

\(z - \bar{z} = 2bi\)  (always imaginary)

\(z \cdot \bar{z} = a^2 + b^2 = |z|^2\)

\(\overline{z_1 + z_2} = \bar{z}_1 + \bar{z}_2\)

\(\overline{z_1 \cdot z_2} = \bar{z}_1 \cdot \bar{z}_2\)

\(\overline{\bar{z}} = z\)  (conjugate of conjugate = original)

Modulus Properties — \(|z| = \sqrt{a^2 + b^2}\)

\(|z_1 \cdot z_2| = |z_1| \cdot |z_2|\)

\(\left|\dfrac{z_1}{z_2}\right| = \dfrac{|z_1|}{|z_2|}\)  (when \(z_2 \neq 0\))

\(|z_1 + z_2| \leq |z_1| + |z_2|\)  (Triangle Inequality)

Inverse Formulas

Additive inverse: \(-z = -a - bi\)

Multiplicative inverse: \(z^{-1} = \dfrac{\bar{z}}{|z|^2} = \dfrac{a - bi}{a^2 + b^2}\)

Question 1 — Verify properties using \(z_1 = 3-4i,\ z_2 = 4+5i,\ z_3 = -5+6i\)

(i) Verify: Addition is commutative  [\(z_1 + z_2 = z_2 + z_1\)]

\(z_1 + z_2 = (3-4i) + (4+5i) = 7 + i\)

\(z_2 + z_1 = (4+5i) + (3-4i) = 7 + i\)

Both sides equal \(7 + i\), so \(z_1 + z_2 = z_2 + z_1\) ✓

(ii) Verify: Multiplication is commutative  [\(z_1 \cdot z_2 = z_2 \cdot z_1\)]

\(z_1 \cdot z_2 = (3-4i)(4+5i)\)

\(= 12 + 15i - 16i - 20i^2\)

\(= 12 - i + 20 = \mathbf{32 - i}\)  (since \(i^2 = -1\))

\(z_2 \cdot z_1 = (4+5i)(3-4i)\)

\(= 12 - 16i + 15i - 20i^2\)

\(= 12 - i + 20 = \mathbf{32 - i}\)

Both sides equal \(32 - i\) ✓

(iii) Verify: Addition is associative  [\((z_1+z_2)+z_3 = z_1+(z_2+z_3)\)]

Left side: \((z_1 + z_2) + z_3 = (7+i) + (-5+6i) = \mathbf{2 + 7i}\)

Right side: \(z_2 + z_3 = (4+5i) + (-5+6i) = -1 + 11i\)

\(z_1 + (z_2 + z_3) = (3-4i) + (-1+11i) = \mathbf{2 + 7i}\)

Both sides equal \(2 + 7i\) ✓

(iv) Verify: Multiplication is associative  [\((z_1 \cdot z_2) \cdot z_3 = z_1 \cdot (z_2 \cdot z_3)\)]

From (ii), \(z_1 \cdot z_2 = 32 - i\)

Left side: \((32-i)(-5+6i) = -160 + 192i + 5i - 6i^2 = -160 + 197i + 6 = \mathbf{-154 + 197i}\)

Now find \(z_2 \cdot z_3\):

\(z_2 \cdot z_3 = (4+5i)(-5+6i) = -20 + 24i - 25i + 30i^2 = -20 - i - 30 = -50 - i\)

Right side: \(z_1 \cdot (z_2 \cdot z_3) = (3-4i)(-50-i)\)

\(= -150 - 3i + 200i + 4i^2 = -150 + 197i - 4 = \mathbf{-154 + 197i}\)

Both sides equal \(-154 + 197i\) ✓

(v) Verify: Distributive property  [\(z_1(z_2+z_3) = z_1 z_2 + z_1 z_3\)]

\(z_2 + z_3 = (4+5i) + (-5+6i) = -1 + 11i\)

Left side: \(z_1(z_2+z_3) = (3-4i)(-1+11i)\)

\(= -3 + 33i + 4i - 44i^2 = -3 + 37i + 44 = \mathbf{41 + 37i}\)

Right side: \(z_1 z_2 = 32 - i\) (from part ii)

\(z_1 z_3 = (3-4i)(-5+6i) = -15 + 18i + 20i - 24i^2 = -15 + 38i + 24 = 9 + 38i\)

\(z_1 z_2 + z_1 z_3 = (32-i) + (9+38i) = \mathbf{41 + 37i}\)

Both sides equal \(41 + 37i\) ✓

Question 2 — Proofs

(a) Prove that \(z + \bar{z}\) is always real.

Let \(z = a + bi\) where \(a, b \in \mathbb{R}\)

Then \(\bar{z} = a - bi\)

\(z + \bar{z} = (a+bi) + (a-bi) = 2a\)

Since \(2a\) is real (no imaginary part), \(z + \bar{z}\) is always real. ✓

(b) Prove that \(z - \bar{z}\) is always imaginary.

Let \(z = a + bi\), then \(\bar{z} = a - bi\)

\(z - \bar{z} = (a+bi) - (a-bi) = 2bi\)

Since \(2bi\) is purely imaginary (for \(b \neq 0\)), \(z - \bar{z}\) is imaginary. ✓

(c) Prove that \(|z_1 \cdot z_2| = |z_1| \cdot |z_2|\)

Let \(z_1 = a + bi\) and \(z_2 = c + di\)

\(z_1 \cdot z_2 = (ac - bd) + (ad + bc)i\)

\(|z_1 \cdot z_2| = \sqrt{(ac-bd)^2 + (ad+bc)^2}\)

\(= \sqrt{a^2c^2 - 2abcd + b^2d^2 + a^2d^2 + 2abcd + b^2c^2}\)

\(= \sqrt{a^2c^2 + a^2d^2 + b^2c^2 + b^2d^2}\)

\(= \sqrt{a^2(c^2+d^2) + b^2(c^2+d^2)} = \sqrt{(a^2+b^2)(c^2+d^2)}\)

\(= \sqrt{a^2+b^2} \cdot \sqrt{c^2+d^2} = |z_1| \cdot |z_2|\) ✓

(d) Prove that \(\left|\dfrac{z_1}{z_2}\right| = \dfrac{|z_1|}{|z_2|}\) where \(z_2 \neq 0\)

Let \(z = \dfrac{z_1}{z_2}\), so \(z_1 = z \cdot z_2\)

Taking modulus: \(|z_1| = |z \cdot z_2| = |z| \cdot |z_2|\)  (using part c)

Dividing both sides by \(|z_2|\):  \(|z| = \dfrac{|z_1|}{|z_2|}\)

Therefore \(\left|\dfrac{z_1}{z_2}\right| = \dfrac{|z_1|}{|z_2|}\) ✓

Question 3 — Find the additive inverses

Rule: Additive inverse of \(z = a+bi\) is \(-z = -a - bi\), because \(z + (-z) = 0\).

(i) \(3 + 5i\)   (ii) \(6 - 5i\)   (iii) \((11, 0)\)   (iv) \(\left(\tfrac{2}{3}, 0\right)\)   (v) \(\left(\tfrac{5}{7}, -\tfrac{7}{5}\right)\)   (vi) \(\left(0, \tfrac{3}{8}\right)\)

(i) Additive inverse of \(3+5i\) is \(\mathbf{-3-5i}\)

    Check: \((3+5i)+(-3-5i) = 0\) ✓

(ii) Additive inverse of \(6-5i\) is \(\mathbf{-6+5i}\)

    Check: \((6-5i)+(-6+5i) = 0\) ✓

(iii) \((11,0) = 11+0i\). Additive inverse: \(\mathbf{-11}\)

(iv) \(\left(\tfrac{2}{3},0\right) = \tfrac{2}{3}\). Additive inverse: \(\mathbf{-\tfrac{2}{3}}\)

(v) \(\left(\tfrac{5}{7},-\tfrac{7}{5}\right) = \tfrac{5}{7} - \tfrac{7}{5}i\). Additive inverse: \(\mathbf{-\tfrac{5}{7} + \tfrac{7}{5}i}\)

(vi) \(\left(0,\tfrac{3}{8}\right) = \tfrac{3}{8}i\). Additive inverse: \(\mathbf{-\tfrac{3}{8}i}\)

Question 4 — Find the multiplicative inverses

Rule: \(z^{-1} = \dfrac{\bar{z}}{|z|^2} = \dfrac{a-bi}{a^2+b^2}\)

(i) \(3 + 5i\)

\(\bar{z} = 3-5i\),   \(|z|^2 = 9+25 = 34\)

\(z^{-1} = \dfrac{3-5i}{34} = \mathbf{\dfrac{3}{34} - \dfrac{5}{34}i}\)

Check: \((3+5i)\!\left(\dfrac{3-5i}{34}\right) = \dfrac{9+25}{34} = 1\) ✓

(ii) \(8i\)

\(z = 0+8i\),   \(\bar{z} = -8i\),   \(|z|^2 = 64\)

\(z^{-1} = \dfrac{-8i}{64} = \mathbf{-\dfrac{1}{8}i}\)

Check: \((8i)\!\left(-\tfrac{1}{8}i\right) = -i^2 = 1\) ✓

(iii) \((10, 0)\)

\(z = 10\),   \(\bar{z} = 10\),   \(|z|^2 = 100\)

\(z^{-1} = \dfrac{10}{100} = \mathbf{\dfrac{1}{10}}\)

(iv) \((12, -7)\)

\(z = 12-7i\),   \(\bar{z} = 12+7i\),   \(|z|^2 = 144+49 = 193\)

\(z^{-1} = \dfrac{12+7i}{193} = \mathbf{\dfrac{12}{193} + \dfrac{7}{193}i}\)

Check: \((12-7i)(12+7i) = 144+49 = 193\), so \(\dfrac{193}{193} = 1\) ✓

(v) \((-8, 0)\)

\(z = -8\),   \(\bar{z} = -8\),   \(|z|^2 = 64\)

\(z^{-1} = \dfrac{-8}{64} = \mathbf{-\dfrac{1}{8}}\)

(vi) \(\left(0, -\tfrac{3}{2}\right)\)

\(z = -\tfrac{3}{2}i\),   \(\bar{z} = \tfrac{3}{2}i\),   \(|z|^2 = \tfrac{9}{4}\)

\(z^{-1} = \dfrac{\tfrac{3}{2}i}{\tfrac{9}{4}} = \dfrac{3}{2}i \cdot \dfrac{4}{9} = \mathbf{\dfrac{2}{3}i}\)

Check: \(\left(-\tfrac{3}{2}i\right)\!\left(\tfrac{2}{3}i\right) = -i^2 = 1\) ✓

Question 5 — Additive and multiplicative inverses by definition

(i) \((2, 3)\) i.e. \(2 + 3i\)

Additive inverse — find \(z\) such that \((2+3i)+z = 0\):

\(z = -(2+3i) = \mathbf{-2-3i}\) ✓

Multiplicative inverse — find \(z\) such that \((2+3i) \cdot z = 1\):

\(z = \dfrac{1}{2+3i} = \dfrac{2-3i}{(2)^2+(3)^2} = \dfrac{2-3i}{13} = \mathbf{\dfrac{2}{13} - \dfrac{3}{13}i}\) ✓

(ii) \((-4, 5)\) i.e. \(-4 + 5i\)

Additive inverse — find \(z\) such that \((-4+5i)+z = 0\):

\(z = -(-4+5i) = \mathbf{4-5i}\) ✓

Multiplicative inverse — find \(z\) such that \((-4+5i) \cdot z = 1\):

\(z = \dfrac{1}{-4+5i} = \dfrac{-4-5i}{(-4)^2+(5)^2} = \dfrac{-4-5i}{41} = \mathbf{-\dfrac{4}{41} - \dfrac{5}{41}i}\) ✓

Question 6 — Verify conjugate/modulus properties using \(z=4-3i\), \(z_1=3-2i\), \(z_2=2+3i\)

(i) Verify: \(|z| = |-z| = |\bar{z}| = |-\bar{z}|\)

\(|z| = |4-3i| = \sqrt{16+9} = \sqrt{25} = 5\)

\(|-z| = |-4+3i| = \sqrt{16+9} = 5\) ✓

\(|\bar{z}| = |4+3i| = \sqrt{16+9} = 5\) ✓

\(|-\bar{z}| = |-4-3i| = \sqrt{16+9} = 5\) ✓

All four are equal to 5. ✓

(ii) Verify: \(\overline{\bar{z}} = z\)  (conjugate of conjugate = original)

\(z = 4-3i\)

\(\bar{z} = 4+3i\)

\(\overline{\bar{z}} = \overline{4+3i} = 4-3i = z\) ✓

(iii) Verify: \(z \cdot \bar{z} = |z|^2\)

\(z = 4-3i\),   \(\bar{z} = 4+3i\)

\(z \cdot \bar{z} = (4-3i)(4+3i) = 16 + 12i - 12i - 9i^2 = 16 + 9 = 25\)

\(|z|^2 = 5^2 = 25\)

\(z \cdot \bar{z} = |z|^2 = 25\) ✓

(iv) Verify: \(\overline{z_1 + z_2} = \bar{z}_1 + \bar{z}_2\)

Left side: \(z_1+z_2 = (3-2i)+(2+3i) = 5+i\),   so \(\overline{z_1+z_2} = 5-i\)

Right side: \(\bar{z}_1 = 3+2i\),   \(\bar{z}_2 = 2-3i\)

\(\bar{z}_1 + \bar{z}_2 = (3+2i)+(2-3i) = 5-i\) ✓

(v) Verify: \(\overline{z_1 \cdot z_2} = \bar{z}_1 \cdot \bar{z}_2\)

Left side: \(z_1 \cdot z_2 = (3-2i)(2+3i) = 6+9i-4i-6i^2 = 6+5i+6 = 12+5i\)

\(\overline{z_1 \cdot z_2} = \overline{12+5i} = 12-5i\)

Right side: \(\bar{z}_1 \cdot \bar{z}_2 = (3+2i)(2-3i) = 6-9i+4i-6i^2 = 6-5i+6 = 12-5i\) ✓

(vi) Verify: \(\overline{\left(\dfrac{z_1}{z_2}\right)} = \dfrac{\bar{z}_1}{\bar{z}_2}\)

Find \(\dfrac{z_1}{z_2} = \dfrac{3-2i}{2+3i}\):

\(= \dfrac{(3-2i)(2-3i)}{(2+3i)(2-3i)} = \dfrac{6-9i-4i+6i^2}{4+9} = \dfrac{6-13i-6}{13} = \dfrac{-13i}{13} = -i\)

Left side: \(\overline{\left(\dfrac{z_1}{z_2}\right)} = \overline{-i} = i\)

Find \(\dfrac{\bar{z}_1}{\bar{z}_2} = \dfrac{3+2i}{2-3i}\):

\(= \dfrac{(3+2i)(2+3i)}{(2-3i)(2+3i)} = \dfrac{6+9i+4i+6i^2}{4+9} = \dfrac{6+13i-6}{13} = \dfrac{13i}{13} = i\)

Both sides equal \(i\) ✓

Question 7 — Express in \(a+bi\) form and verify Triangle Inequality (\(z_1=3-2i\), \(z_2=2-3i\))

(i) \(\dfrac{z_1 + z_2}{z_1}\)

\(z_1+z_2 = (3-2i)+(2-3i) = 5-5i\)

\(\dfrac{5-5i}{3-2i} = \dfrac{(5-5i)(3+2i)}{(3-2i)(3+2i)} = \dfrac{15+10i-15i-10i^2}{9+4}\)

\(= \dfrac{15+10-5i}{13} = \dfrac{25-5i}{13} = \mathbf{\dfrac{25}{13} - \dfrac{5}{13}i}\)

Triangle Inequality:  \(|z_1+z_2| \leq |z_1|+|z_2|\)

\(|5-5i| = \sqrt{50} = 5\sqrt{2} \approx 7.07\)

\(|z_1|+|z_2| = \sqrt{13}+\sqrt{13} = 2\sqrt{13} \approx 7.21\)

\(5\sqrt{2} < 2\sqrt{13}\) — Inequality holds ✓

(ii) \(\dfrac{z_1 - z_2}{z_1}\)

\(z_1-z_2 = (3-2i)-(2-3i) = 1+i\)

\(\dfrac{1+i}{3-2i} = \dfrac{(1+i)(3+2i)}{(3-2i)(3+2i)} = \dfrac{3+2i+3i+2i^2}{13}\)

\(= \dfrac{3+5i-2}{13} = \dfrac{1+5i}{13} = \mathbf{\dfrac{1}{13} + \dfrac{5}{13}i}\)

Triangle Inequality:  \(|1+i| = \sqrt{2} \approx 1.41\)

\(|z_1|+|z_2| = 2\sqrt{13} \approx 7.21\),   \(\sqrt{2} < 2\sqrt{13}\) ✓

(iii) \(\dfrac{z_1 + z_2}{z_2}\)

\(z_1+z_2 = 5-5i\) (from part i)

\(\dfrac{5-5i}{2-3i} = \dfrac{(5-5i)(2+3i)}{(2-3i)(2+3i)} = \dfrac{10+15i-10i-15i^2}{4+9}\)

\(= \dfrac{10+15+5i}{13} = \dfrac{25+5i}{13} = \mathbf{\dfrac{25}{13} + \dfrac{5}{13}i}\)

Triangle Inequality:  \(|5-5i| = 5\sqrt{2} < 2\sqrt{13}\) ✓ (same as part i)

Question 8 — Find real and imaginary parts

(i) \((\sqrt{2}+i)^{-2}\)

Find \(z^{-1}\) first:  \(|z|^2 = 2+1 = 3\),   \(z^{-1} = \dfrac{\sqrt{2}-i}{3}\)

\((z^{-1})^2 = \left(\dfrac{\sqrt{2}-i}{3}\right)^2 = \dfrac{2-2\sqrt{2}i+i^2}{9} = \dfrac{2-1-2\sqrt{2}i}{9} = \dfrac{1-2\sqrt{2}i}{9}\)

Real part: \(\mathbf{\dfrac{1}{9}}\)  |  Imaginary part: \(\mathbf{-\dfrac{2\sqrt{2}}{9}}\)

(ii) \((1-\sqrt{3}\,i)^{-1}\)

\(|z|^2 = 1+3 = 4\),   \(z^{-1} = \dfrac{1+\sqrt{3}\,i}{4}\)

Real part: \(\mathbf{\dfrac{1}{4}}\)  |  Imaginary part: \(\mathbf{\dfrac{\sqrt{3}}{4}}\)

(iii) \((\sqrt{3}-i)^{-2}\)

\(|z|^2 = 3+1 = 4\),   \(z^{-1} = \dfrac{\sqrt{3}+i}{4}\)

\((z^{-1})^2 = \dfrac{(\sqrt{3}+i)^2}{16} = \dfrac{3+2\sqrt{3}\,i+i^2}{16} = \dfrac{3-1+2\sqrt{3}\,i}{16} = \dfrac{2+2\sqrt{3}\,i}{16} = \dfrac{1+\sqrt{3}\,i}{8}\)

Real part: \(\mathbf{\dfrac{1}{8}}\)  |  Imaginary part: \(\mathbf{\dfrac{\sqrt{3}}{8}}\)

(iv) \((2i-\sqrt{3})^{-1}\)

\(z = -\sqrt{3}+2i\),   \(\bar{z} = -\sqrt{3}-2i\),   \(|z|^2 = 3+4 = 7\)

\(z^{-1} = \dfrac{-\sqrt{3}-2i}{7}\)

Real part: \(\mathbf{-\dfrac{\sqrt{3}}{7}}\)  |  Imaginary part: \(\mathbf{-\dfrac{2}{7}}\)

(v) \(\left(\dfrac{1}{4i-5}\right)^{-1}\)

The expression \(\left(\dfrac{1}{4i-5}\right)^{-1} = 4i-5 = -5+4i\)

(Taking the inverse of a fraction just flips it.)

Real part: \(\mathbf{-5}\)  |  Imaginary part: \(\mathbf{4}\)

(vi) \(\left(\dfrac{3+4i}{5i-4}\right)^{-2}\)

Step 1 — Simplify \(\dfrac{3+4i}{-4+5i}\):

\(= \dfrac{(3+4i)(-4-5i)}{(-4+5i)(-4-5i)} = \dfrac{-12-15i-16i-20i^2}{16+25}\)

\(= \dfrac{-12+20-31i}{41} = \dfrac{8-31i}{41}\)

Step 2 — Invert: \(\left(\dfrac{8-31i}{41}\right)^{-1} = \dfrac{41}{8-31i} = \dfrac{41(8+31i)}{64+961} = \dfrac{41(8+31i)}{1025} = \dfrac{8+31i}{25}\)

Step 3 — Square: \(\left(\dfrac{8+31i}{25}\right)^2 = \dfrac{(8+31i)^2}{625} = \dfrac{64+496i+961i^2}{625} = \dfrac{64-961+496i}{625} = \dfrac{-897+496i}{625}\)

Real part: \(\mathbf{-\dfrac{897}{625}}\)  |  Imaginary part: \(\mathbf{\dfrac{496}{625}}\)

Question 9 — If \(x = 1-5i\), show that \(x^2 - 2x + 26 = 0\)

Show that \(x^2 - 2x + 26 = 0\) when \(x = 1 - 5i\)

Find \(x^2\): \((1-5i)^2 = 1 - 10i + 25i^2 = 1-10i-25 = -24-10i\)

Find \(2x\): \(2(1-5i) = 2-10i\)

\(x^2 - 2x + 26 = (-24-10i) - (2-10i) + 26\)

\(= (-24-2+26) + (-10i+10i)\)

\(= 0 + 0i = 0\) ✓

Question 10 — If \(x = 2 + \sqrt{3}\,i\), find \(x^3 - 4x^2 + 8x + 55\)

Find the value of \(x^3 - 4x^2 + 8x + 55\) when \(x = 2 + \sqrt{3}\,i\)

Find \(x^2\): \((2+\sqrt{3}\,i)^2 = 4 + 4\sqrt{3}\,i + 3i^2 = 4+4\sqrt{3}\,i-3 = 1+4\sqrt{3}\,i\)

Find \(x^3 = x \cdot x^2 = (2+\sqrt{3}\,i)(1+4\sqrt{3}\,i)\):

\(= 2 + 8\sqrt{3}\,i + \sqrt{3}\,i + 4\sqrt{3}\,i^2 = 2 + 9\sqrt{3}\,i - 4\sqrt{3}\)

\(= (2-4\sqrt{3}) + 9\sqrt{3}\,i\)

Now evaluate: \(x^3 - 4x^2 + 8x + 55\)

\(= \left[(2-4\sqrt{3}) + 9\sqrt{3}\,i\right] - 4\left[1+4\sqrt{3}\,i\right] + 8\left[2+\sqrt{3}\,i\right] + 55\)

Real: \((2-4\sqrt{3}) + (-4) + 16 + 55 = 69 - 4\sqrt{3}\)

Imaginary: \(9\sqrt{3} - 16\sqrt{3} + 8\sqrt{3} = \sqrt{3}\)

Answer: \(\mathbf{(69-4\sqrt{3}) + \sqrt{3}\,i}\)

⚠️ Common Mistakes to Avoid

Forgetting to negate BOTH parts for additive inverse. The additive inverse of \(a+bi\) is \(-a-bi\) — not just \(-a+bi\). Both real and imaginary parts flip sign.
Using the wrong formula for multiplicative inverse. The formula is \(z^{-1} = \dfrac{\bar{z}}{|z|^2}\). A common mistake is forgetting to divide by \(|z|^2\) — just using the conjugate alone is not the inverse.
Triangle inequality direction. It is \(|z_1+z_2| \leq |z_1|+|z_2|\) — the modulus of the SUM is less than or equal to the SUM of moduli. Not the other way around. Equality only holds when both numbers point in the same direction.

📝 Summary

  • Complex numbers obey commutative, associative, and distributive laws — same as real numbers.
  • Conjugate and modulus have special properties: \(z\bar{z}=|z|^2\), \(\overline{z_1 z_2}=\bar{z}_1\bar{z}_2\), \(|z_1 z_2|=|z_1||z_2|\).
  • Additive inverse = \(-z\); Multiplicative inverse = \(\dfrac{\bar{z}}{|z|^2}\). Triangle inequality: \(|z_1+z_2| \leq |z_1|+|z_2|\).
